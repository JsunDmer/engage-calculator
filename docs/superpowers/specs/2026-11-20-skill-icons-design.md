# 纹章士技能图标 + 职业武器筛选与成长率对比 设计

## 意图

纹章士详情页技能行加游戏内技能图标，提升图鉴辨识度；职业页增加武器类型筛选与成长率对比表格，方便选转职路线；完成后推送 GitHub 并发布 v1.3.0 Release。

## 目标 / 非目标

- 目标：详情页全部技能行（技能链各阶、结合武器/指令技/特技、解锁功能/资质）左侧显示图标；缺图技能显示占位，不报错。
- 非目标：不新增网络图片源、不改列表页/资质检索页/牵绊戒指页、不动计算器逻辑。

## 方案取舍

1. **xlsx 内嵌图标离线提取（选定）**：图标已在数据表里（drawing1 锚定技能表 D 列 42 张，drawing2 锚定进化链表 D–I 列 289 张），离线可复现，与现有 build_assets.py 流程一致。
2. 网络抓取 wiki 图标：覆盖可能更全但引入外部依赖与版权/稳定性问题，且大部分图标本地已有，不采用。
3. 仅技能链各阶加图标：改动最小但结合武器等无图标，用户已选全量方案。

## 设计

- `tools/build_assets.py` 新增图标提取：解析两个 drawing 的锚点 → 单元格技能名；名称按现有 normalizeName 规则归一（去点/空格、＋→+、小写）；同名技能去重；按图片内容 md5 去重后转无损 webp，输出 `assets/skills/skill_<hash8>.webp`（299 张 ≈ 0.9MB）；engage.json 增加顶层 `skillIcons: {归一名: 路径}`。
- core `Model.kt`：Dataset 增加 `skillIcons: Map<String, String>`（默认空，向后兼容）。
- UI：`SkillLine` 名称行左侧加图标；`ChainStep` 顶部加图标；图标经 `AvatarCache` 加载，缺失时用 surfaceVariant 占位方块（技能图标不加头像金边，用独立小组件）。
- 覆盖：505 行中 375 行有图标（结合武器/部分结合特技数据表无图，显示占位）。

## 职业页增强（用户已确认交互形式）

- **武器筛选 chips**：搜索框下新增一排武器类型 chips（剑/枪/斧/弓/短剑/体术/魔道书/杖/龙石/炮弹，单选可取消），点选筛出武器字段含该类型的职业；行内副标题显示该职业对应武器的资质等级（如「剑A、杖C」）。与现有 tier/section 筛选、文本搜索叠加生效。匹配按武器词边界（「剑」不误中「短剑」）。
- **成长率对比表格**：列表页顶部加「列表 / 成长率」视图切换（与纹章士页 FilterChip 风格一致）。成长率视图为可横滚表格：首列冻结职业名，后接 9 项成长率 + 合计，数值沿用 GrowthScale.classStat/classTotal 分级着色；行点击仍进详情。筛选条件对两种视图同样生效。
- 取舍：行内左滑展开手势隐蔽、可发现性差；详情页滑动切表一次只能看一个职业，均不利于「对比」目标，故用同屏表格。

## 发布

提交推送 main → 打 tag `v1.3.0` → CI 自动构建并发布 Release（沿用 android.yml）。
